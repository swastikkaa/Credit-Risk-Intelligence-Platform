# Tableau Dashboard

The interactive dashboard presents the project as a three-stage risk analytics workflow:

1. **Financial Impact** — translates predicted risk into default losses avoided, opportunity cost, net dollar savings, and portfolio loss reduction.
2. **Portfolio Risk Segmentation** — uses SQL-driven EDA to identify where default risk is concentrated, including the FICO × DTI interaction.
3. **ML Diagnostics** — evaluates the XGBoost model, threshold trade-offs, and a research-inspired loan-description text experiment.
